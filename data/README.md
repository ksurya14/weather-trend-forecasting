# Data Folder

Download the Kaggle dataset from:

https://www.kaggle.com/datasets/nelgiriyewithana/global-weather-repository

Place the CSV here as:

```text
data/Global Weather Repository.csv
```

The script also accepts:

```text
data/GlobalWeatherRepository.csv
```

The raw dataset is not committed because Kaggle datasets can have separate download and sharing terms.
