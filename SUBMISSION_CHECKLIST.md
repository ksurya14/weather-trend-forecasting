# Submission Checklist

Use this checklist before sending the Google Form.

## Repository

- Create a GitHub repository named `weather-trend-forecasting`.
- Push the project folder contents.
- Keep the repository public and open-source during evaluation, or make it private and add:
  - `community@pmaccelerator.io`
  - `hr@pmaccelerator.io`
- Confirm GitHub allows clone/download access.

## Files to Include

- `README.md`
- `requirements.txt`
- `src/weather_trend_forecasting.py`
- `data/GlobalWeatherRepository.csv`
- `report/Weather_Trend_Forecasting_Report.md`
- `outputs/model_metrics.csv`
- `outputs/forecast_predictions.csv`
- `outputs/feature_importance.csv`
- `outputs/anomaly_detection_results.csv`
- `outputs/country_monthly_temperature_trends.csv`
- `outputs/air_quality_weather_correlations.csv`
- `outputs/country_spatial_temperature_summary.csv`
- `outputs/figures/`

The cleaned full CSV and trained model binaries are ignored by default because they are large and reproducible from the included raw CSV.

## Demo Video Script

Target length: 1-2 minutes.

1. Show the GitHub repository structure.
2. Open `README.md` and explain how to run the project.
3. Open `src/weather_trend_forecasting.py` and mention the main workflow: cleaning, EDA, anomaly detection, forecasting, feature importance, climate/environment, and spatial analysis.
4. Open `outputs/model_metrics.csv` and mention that the ensemble model achieved the best RMSE.
5. Show the generated figures in `outputs/figures/`.
6. Open `report/Weather_Trend_Forecasting_Report.md` and point out the PM Accelerator mission, methodology, metrics, and insights.

## Google Form

Submit:

- GitHub repository URL
- Demo video URL
- Any short note that the project completes the advanced assessment path
