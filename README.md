# Weather Trend Forecasting

End-to-end data science assessment project using Kaggle's Global Weather Repository dataset. The project covers the required basic assessment and adds advanced analysis: anomaly detection, multiple forecasting models, an ensemble model, feature importance, air-quality correlation, climate patterns, and spatial/geographical analysis.

Run the analysis:


## Methodology

1. Data cleaning and preprocessing

The script parses `last_updated` as the time-series field, removes unusable timestamp/temperature rows, imputes missing values, clips numeric outliers using the IQR rule, and creates normalized numeric columns.

2. Exploratory data analysis

The project generates temperature and precipitation trend charts, summary statistics, country-level comparisons, and a correlation heatmap for weather and air-quality variables.

3. Anomaly detection

Isolation Forest is used to flag unusual weather observations based on temperature, precipitation, humidity, wind, pressure, and available air-quality features.

4. Forecasting

The target is temperature. The script creates date features, seasonal sine/cosine features, lag features, and rolling temperature features. It compares:

- Persistence baseline
- Linear Regression
- Random Forest
- Gradient Boosting
- Average ensemble model

Evaluation metrics include MAE, RMSE, MAPE, and R2.

5. Advanced analysis

The project includes feature importance, air-quality/weather correlation, country and continent temperature patterns, and an interactive global spatial temperature map.
